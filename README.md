# Login & Registration System - C++

This project is a Login and Registration System developed in C++ as part of the CodeAlpha Internship.  
It allows users to register with a username and password, store credentials using file handling, and login with proper validation.

## Features
- User registration system
- Login authentication
- File handling for storing credentials
- Simple and secure console-based system

## Tech Stack
- Language: C++
- Concepts Used: File Handling, Functions, Conditional Statements, Loops, Input/Output
